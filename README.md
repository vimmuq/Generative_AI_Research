## How to Find Relevant Files

Select the folder that matches the type of research material you need. Literature sources are stored in `Literature Review documents`, survey materials are in `Quantitative Analysis`, interview materials are in `Qualitative Analysis`, project reports are in `Drafts and Reports`, and supporting files are in `Additional Material`. Files have descriptive names and can also be located using the repository search bar.
